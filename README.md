# CampusGPT - AI Chatbot 🎓🤖

CampusGPT is an AI-powered chatbot developed using Python, Hugging Face Transformers, GPT-2, and Gradio.

The chatbot can answer student-related questions using:
- Rule-based logic
- AI-generated responses
- Conversation memory
- Custom question-answer database

# Features
 AI Chatbot using GPT-2  
 Smart Hybrid Brain  
 Conversation Memory  
 Custom Q&A Support  
 Gradio Web Interface  
 Beginner-Friendly Project  

# Technologies Used

- Python
- Hugging Face Transformers
- GPT-2
- Gradio
- Pandas
